# Security policy

gantline lets a model press keys in its own terminal, and the README's warning describes what that exposes by design. Report anything beyond it: a way to make gantline type somewhere it shouldn't, a guard that can be bypassed, a secret it writes to a file or command line, or a problem in how it edits `settings.json`.

Email justin@justinstimatze.com rather than opening a public issue or pull request. I'll acknowledge the report within 7 days and send an initial assessment within 30. Disclosure defaults to 90 days after the report, and we can agree on a different timeline.

Only the latest commit on `main` is supported. There are no release branches, so fixes land there.
